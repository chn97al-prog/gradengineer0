# تجهيزات المهندس — موقع الطلب والتصميم ثلاثي الأبعاد

## شنو بيه المشروع
- `index.html` — صفحة الهبوط
- `services.html` — صفحة اختيار الموديلات (الملكي شغّال بالكامل، الباقي "قريباً" لحد ما توفر صورهم)
- `customize.html` + `assets/js/customizer.js` — استوديو التصميم ثلاثي الأبعاد (Three.js): مانيكان يلبس وشاح وقبعة، تكتب النص وتختار اللون والخط وتدور الموديل، وتصدّر PNG أو ترسل الطلب.
- `netlify/functions/submit-order.js` — فنكشن سيرفرلس توصل الطلب لتيليكرام + تسجله بكوكل شيتس.

## ملاحظة مهمة عن الـ 3D
طلبت موديل 3D فعلي أدور وأتحكم بيه — هذا اللي مسويه بالضبط، بس خلي بالك: الموديل مبني بالكود (أشكال هندسية بسيطة: أسطوانة + كرة للمانيكان، شريط منحني للوشاح، صندوق للقبعة) مو مسحوب من ملف 3D جاهز أو صورة حقيقية، لأنه ماكو عندنا ملفات/صور جاهزة الحين. النتيجة تصميم **أنيق وستايلايزد** (stylized) — يعطي فكرة دقيقة عن الشكل واللون والنص، بس مو صورة فوتوغرافية واقعية 100%.

إذا بعدين تريد شكل أواقعي أكثر (قماش حقيقي، مانيكان بملامح)، فيه طريقين:
1. **تجهيز ملفات 3D جاهزة (GLB/GLTF)** لموديل مانيكان + وشاح + قبعة (تنسوي بأي برنامج 3D مثل Blender أو تنشترى من مواقع مثل Sketchfab)، وأنا أدمجها بنفس الكود بدل الأشكال الهندسية.
2. **الاكتفاء بالطريقة الحالية** لأنها فعلاً 3D حقيقي (تدور وتكبر وتصغر) وخفيفة وسريعة التحميل، وتنفع ممتاز لعرض اللون والنص والموديل العام.

## شلون تشغّله محلياً
ما يحتاج بناء، بس شغّل سيرفر بسيط بالمجلد (مثلاً `npx serve .` أو Live Server بـ VS Code) لأنه يستخدم ES Modules، وفتحه مباشرة كملف (`file://`) ما يشتغل زين.

## قبل الرفع على Netlify
1. `npm install` بمجلد المشروع (يجيب مكتبة `googleapis`).
2. اربط المشروع بـ GitHub وبعدين بـ Netlify متل مشروعك الحالي.
3. من **Site settings → Environment variables** ضيف:
   - `TELEGRAM_BOT_TOKEN` — نفس التوكن اللي عندك بمشروع تجهيزات المهندس الحالي (لا تحطه بالكود مباشرة، هذا سبب استخدام الفنكشن).
   - `TELEGRAM_CHAT_ID` — آيدي الشات/كروب المستلم للطلبات.
   - `GOOGLE_SERVICE_ACCOUNT_JSON` — محتوى ملف حساب خدمة كوكل (JSON) بسطر وحد. تسويه من Google Cloud Console → IAM → Service Accounts → إنشاء مفتاح JSON، وبعدين تشارك الشيت (Google Sheet) مع إيميل حساب الخدمة كـ Editor.
   - `GOOGLE_SHEET_ID` — الآيدي اللي يبين بلينك الشيت بين `/d/` و `/edit`.
4. بالشيت سوي شيت بالاسم `Orders` وحط بالصف الأول العناوين: التاريخ، الموديل، نص الوشاح، نص القبعة، اللون، الخط، الاسم، الهاتف، الكلية.

## إضافة موديلات جديدة
بملف `assets/js/customizer.js`:
- ضيف مفتاح جديد بـ `MODEL_LABELS`.
- بطاقة جديدة بـ `services.html` تودي لـ `customize.html?model=xxx`.
- إذا تريد شكل مختلف للمانيكان/الوشاح/القبعة حسب الموديل، أقدر أبنيلك فنكشن `buildSashCurvePoints` وشكل القبعة يتغيرون حسب `MODEL_ID`.

## الأمان
توكن تيليكرام وبيانات حساب كوكل موجودين بس بمتغيرات البيئة بالسيرفر (Netlify Functions)، ما ينبعثون أبداً للمتصفح — نفس أسلوب مشروعك الحالي.
